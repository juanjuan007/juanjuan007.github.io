**思路**

&lt;M一&gt;

對於第一種操作，我們需要將兩者放入同個並查集表示相同;

第二種操作就有點複雜，我們需要紀錄吃與被吃的關係，可以觀察到只有三種類型，我們不妨使用數字來做代替，用 $x \equiv y+1 \mod 3$ 表 $x$ 可以吃 $y$，

也就是對於每個編號，要紀錄 : 它的首領、與其種類的偏移量，那我們就可據此作判斷，先判斷是不是在同個群，再判斷偏移量。

Time : $O(K \log N)$

<br>

Code :

實作上，我們可以統一使用一個函式，傳入偏移量即可完成。

```cpp
#include<bits/stdc++.h>
using namespace std;

vector<int>f,p;

int find_root(int x){
    if(f[x]==x) return(x);
    int nw = find_root(f[x]);
    p[x] = (p[x] + p[f[x]])%3; f[x] = nw; 
    return(f[x]);
}

bool Union(int x,int y,int v){
    int px = find_root(x), py = find_root(y);
    if(px==py){
        return(p[x]==(p[y]+v)%3); 
    }else{
        f[px] = py;
        p[px] = (((p[y]+v-p[x])%3)+3)%3;
    }
    return(1);
}

int main(){
    ios::sync_with_stdio(0),cin.tie(0);

    int n,k;
    cin>>n>>k;
    
    f.resize(n); iota(f.begin(),f.end(),0);
    p.assign(n,0);

    int ans = 0;
    int d,x,y;
    while(k--){
        cin>>d>>x>>y;
        x--; y--;
        if(x>=n || y>=n){ ans++; continue; }
        if(!Union(x,y,d-1)) ans++;
    }
    cout<<ans;
    return(0);
}
```

&lt;M二&gt;

在一個並查集中，除了可以維護相同性質外，還可以維護不矛盾的性質。

使用 $A_{x}$ 、 $B_{x}$ 、 $C_{x}$ 分別表示 $x$ 是三種種類的狀況。

那對於第一種操作，我們要判斷 $A_{x}$ 跟 $B_{y}$ 、 $C_{y}$ 是否不同集合，再將 $A_{x}$ 與 $A_{y}$ 合併，另外兩種依此類推;

第二種操作，是判斷 $A_{x}$ 與 $A_{y}$ 、 $C_{y}$ 是否不同集合，再將 $A_{x}$ 與 $B_{y}$ 合併，另外兩種依此類推。

實作上，我們只需要檢查其中一個條件即可，我們可以發現三者關係形成環狀，因此有對稱性。

Time : $O(K \log N)$

<br>

Code:

```cpp
#include<bits/stdc++.h>
using namespace std;

vector<int>f,sz;

int find_root(int x){
    if(f[x]==x) return(x);
    return(f[x] = find_root(f[x]));
}

void Union(int x,int y){
    x = find_root(x); y = find_root(y);
    if(x==y) return;
    if(sz[x] < sz[y]) swap(x,y);
    f[y] = x; sz[x] += sz[y]; 
}

bool same(int x,int y){
    return(find_root(x)==find_root(y));
}

int main(){
    ios::sync_with_stdio(0),cin.tie(0);
    int n,k;
    cin>>n>>k;
    
    f.resize(3*n); iota(f.begin(),f.end(),0);
    sz.assign(3*n,1);

    int ans = 0; int d,x,y;

    while(k--){
        cin>>d>>x>>y;
        x--; y--;

        if(x>=n || y>=n){ ans++; continue; }
        
        if(d==1){
            if(same(3*x,3*y+1) || same(3*x,3*y+2)){
                ans++;
            }else{
                Union(3*x,3*y);
                Union(3*x+1,3*y+1);
                Union(3*x+2,3*y+2);
            }
        }else if(d==2){
            if(x==y){ ans++; continue; }
            if(same(3*x,3*y) || same(3*x,3*y+2)){
                ans++;
            }else{
                Union(3*x,3*y+1);
                Union(3*x+1,3*y+2);
                Union(3*x+2,3*y);
            }
        }
    }
    cout<<ans;
    return(0);
}
```
